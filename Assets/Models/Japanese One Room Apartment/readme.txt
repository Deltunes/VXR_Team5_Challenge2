GENERAL NOTES

- FBX files provided for troubleshooting but recommended to use the Blender file and export the pieces out.

- To use your own laptop and TV screen images, hide the "laptop display off" or "tv screen off" objects and show "laptop display on" or "tv screen on" objects. Replace the material's texture image with your own.

- If moving some objects with multiple pieces like the laptop, fridge, shower doors, etc, its best to parent them together first.


UNITY

- Recommended to use SSAO. See "recommended-SSAO-settings.jpg" in the Unity package.

- Enable "Realtime Reflection Probes" in the project Quality settings for proper reflections.
